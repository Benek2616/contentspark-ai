# ⚡ ContentSpark AI

Szybki generator pomysłów na content do social mediów.

## Co robi?

- Wybierasz platformę (TikTok, Instagram, YouTube Shorts, X)
- Podajesz tematykę / niszę
- Wybierasz styl (edukacyjny, rozrywkowy, storytelling, prowokujący, motywacyjny)
- Dostajesz 5 gotowych pomysłów z:
  - tytułem / koncepcją
  - gotowym hookiem na start
  - sugerowaną strukturą
  - wskazówkami co do długości i formatu
